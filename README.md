# 地图投影形变实验室 (Web Mercator Lab)

这是一个交互式地图工具，用于直观展示和对比 Web Mercator 投影下各国家的几何面积形变。

### 🌟 核心功能
- **球面平移算法**：基于大圆航线的球面位移计算，保证国家拖拽拉伸时形状不失真。
- **多国独立对比**：支持添加多个国家，并可单独进行拖拽对比。
- **多重轮廓设计**：拖动时保留原位虚线轮廓，方便进行直观比例对比。
- **经典场景预设**：内置“赤道大缩小”、“中美横向对比”、“全球六大领土国”等一键演示。
